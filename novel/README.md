# Xianxia novel manuscript

Working files for the xianxia novel being written by the `xianxia-author`
agent (Chen Wei, an aspiring author) with you as his publisher. Agent
definition: `.claude/agents/xianxia-author.md`.

To start a meeting, ask Claude Code to use the `xianxia-author` agent, or
@-mention it, for example: "Have xianxia-author pitch me his novel."

- `pitch.md`: the current pitch
- `bible.md`: world, cultivation system, characters, glossary
- `outline.md`: arc and chapter outline
- `chapters/`: one file per chapter
- `submission-log.md`: dated record of every exchange with the publisher
